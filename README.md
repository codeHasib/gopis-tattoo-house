# 🖋️ Gopi’s Tattoo Studio — Business Website

🔗 **Live:** https://gopistattoostudio.com

A modern, high-impact business website built for a professional tattoo studio. Designed to showcase services, build trust with potential clients, and drive booking conversions through a clean and engaging user experience.

---

## 🚀 Overview

This project focuses on creating a strong online presence for a tattoo studio, combining visual storytelling with practical user flows.

The goal was to design a website that not only looks premium but also helps users بسهولة explore services, view work, and take action.

---

## ⚡ Key Features

- 🎨 **Portfolio Showcase** — Clean layout to display tattoo work and build trust
- 🧾 **Client Testimonials** — Structured review section to improve credibility
- 📋 **Booking & Inquiry Flow** — User-friendly forms for client communication
- 📱 **Responsive Design** — Optimized experience across mobile and desktop
- ✨ **Smooth Animations** — Subtle transitions for a modern, polished feel
- 📄 **Information Pages** — Clear presentation of services, policies, and studio details

---

## 🧠 Technical Highlights

- Built with **Next.js App Router** for structured routing and performance
- Tailwind CSS used for fast, scalable UI development
- Framer Motion integrated for smooth user interactions
- Focus on clean layout, readability, and real-world usability

---

## 🛠️ Tech Stack

**Frontend:** Next.js, React, Tailwind CSS
**Animations:** Framer Motion
**Icons:** Lucide React
